# 🚦 Road Accident Analysis Dashboard (Power BI)
Power BI dashboard analyzing road accident data with insights on casualties, trends, road types, and geographic risk patterns.


---

## 📌 Project Overview

The **Road Accident Analysis Dashboard** is an interactive analytics solution built using **Power BI** to monitor and analyze road accident data.

This dashboard provides deep insights into **casualties, accident trends, road conditions, and geographic distribution**, helping authorities and analysts make **data-driven decisions** to improve road safety.

It transforms raw accident data into **meaningful visual insights** for better planning and prevention strategies.

---

## 🎯 Objectives

The primary goal of this project is to analyze accident patterns and improve safety measures.

- Analyze **total casualties and accident counts**
- Identify trends in **fatal, serious, and slight injuries**
- Understand **monthly and yearly accident trends**
- Compare **urban vs rural accident distribution**
- Evaluate accident impact based on **road types and conditions**
- Provide actionable insights to reduce accidents

- **Power BI** – Dashboard creation & visualization

- **Excel / CSV Dataset** – Data source

## 📊 Dataset Information

The dataset includes road accident data with attributes such as:

- Number of accidents  
- Casualties (Fatal, Serious, Slight)  
- Vehicle type (Bike, Car, Van, Others)  
- Road type (Single carriageway, Dual carriageway, etc.)  
- Area type (Urban / Rural)  
- Time conditions (Day / Night)  
- Geographic location  

This data helps analyze **risk factors and accident patterns**.

## 🚀 Dashboard Features

### 1. KPI Summary Section

Provides a high-level overview of:
- Total casualties  
- Total accidents  
- Severity breakdown (Fatal, Serious, Slight)  
- Year-over-year percentage change  

---

### 2. Vehicle Type Analysis

Breakdown of casualties by vehicle type:

- 🚲 Bike  
- 🚗 Car  
- 🚐 Van  
- ⚠️ Others  

Helps identify which vehicle category contributes most to accidents.

---

### 3. Monthly Trend Analysis

Tracks **casualties over months** for different years.

- Identifies **seasonal patterns**
- Detects **peak accident periods**

---

### 4. Area-wise Analysis (Urban vs Rural)

Visual comparison of accident distribution:

- Urban areas  
- Rural areas  

Helps understand **where accidents are more frequent**.

---

### 5. Road Type Analysis

Analyzes casualties based on:

- Single carriageway  
- Dual carriageway  
- Roundabout  
- One-way streets  
- Slip roads  

Identifies **high-risk road types**.

---

### 6. Time-based Analysis (Day vs Night)

Compares accident occurrences during:

- 🌞 Day  
- 🌙 Night  

Useful for understanding **visibility and risk factors**.

---

### 7. Geographic Analysis

Interactive map showing accident distribution across regions.

- Identifies **accident hotspots**
- Helps in **regional safety planning**

---

## 🔍 Key Insights Derived

- Majority of casualties come from **car-related accidents**
- **Urban areas** contribute a higher share of accidents
- Most accidents occur on **single carriageway roads**
- Slight injuries dominate, but **fatal cases still critical**
- Accident frequency varies across **months and seasons**
- Daytime accidents are more frequent than nighttime
